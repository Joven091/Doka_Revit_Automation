# Top50 dashboard layout and Doka equipment names

Top50 uses the existing CalculatorStyles resource dictionary in both the Revit add-in and standalone tester. It has a compact header, horizontal workflow tabs, yellow primary action, neutral tables, pale-yellow section headings, and panel inventory beside reusable connector stock. The launcher orders Calculators, Planners / Top50, then Beta / Dome. The existing Dome Beta opens through the dashboard's access gate; D3 slab remains Coming soon.

Equipment names are shared by the screen, diagnostic description and workbook:

| Role in the existing stock calculation | Doka equipment | Article number |
| --- | --- | --- |
| Direct panel joint | Formwork element connector FF20/50 Z | 587533000 |
| Filler/closure joint | Adjustable waling extension FF20/50 | 587532000 |

Verified against Doka's official [Top50 article list](https://www.doka.com/_ext/downloads/itemlists/en/26.pdf), [UAE direct-connector listing](https://shop.doka.com/shop/ae/en/protection-screen-xclimb-60-with-trapezoidal-sheet-enclosure/formwork-element-connector-ff20-50-z/p/587533000/) and [Top50 user information, March 2026](https://direct.doka.com/_ext/downloads/downloadcenter/999732002_2026_03_online.pdf).

This update changes presentation and equipment naming. It retains the selected one-level/per-face quantity basis, reusable stock arithmetic, project identity and planner search rules. The project's 350 mm filler limit is unchanged; the product's available applications do not automatically change the project's layout limits.
