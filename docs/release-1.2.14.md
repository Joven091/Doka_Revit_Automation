# Dashboard 1.2.14

- **Backpropping PDF** — Keep the Load breakdown heading, table, and explanatory note together. If the block fits on a fresh sheet but exceeds the space below the load-transfer schematic, start it on the next sheet.
- **Dokaflex slab formwork** — Click a primary or secondary H20 in the schematic to open that beam’s loading, shear, moment, and deflection diagrams. Both schematic views use this interaction. The diagrams use the shared member plots, and the separate diagram buttons have been removed.
- **Backpropping commands** — Start a calculation from **File → New**.
- **Backpropping storeys** — Choose Props or D3 for each required storey. Props have separate family and size pickers. D3 uses the tower configuration for that storey’s height.
- **Dokaflex loading** — Check all specified slab and access loads acting together. The diagrams show the governing receiving primary and the report includes each primary line.
- **Updates** — Checking for updates shows availability. A newer release offers Yes or No before installation. The Dashboard launcher also offers the separate Revit integration check in its update menu.
- **Backpropping report details** — Enter the cover information under **Calculation setup → Report details**. Saving the calculation includes these fields, and opening it restores them for the next PDF.
