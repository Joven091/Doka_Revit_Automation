# Top50 Planner test release 1.1.17

Historical diagnosis/UI release notes. This source was subsequently merged through PR171. For the new quantity-first and repeatable-search policy, see [top50-quantity-repeatability.md](top50-quantity-repeatability.md).

The Engineering Dashboard now places Top50 Planner in a **Planners** section below **Calculators**. Slab, Beam, Backpropping and the locked Coming soon choices retain their existing behavior. Top50 is an equipment and casting-group planner.

Choose **Diagnose** in the Top50 header from any page, including before import or while optimization runs. The report opens only when clicked. **Refresh**, **Copy report** and **Save report…** work with the active planner session. Copy or save it before closing Revit if a search, import, project or export fails.

The report contains the build/MVID, runtime, current settings, every input wall and its measurement/review/raw DXF evidence, source checksum, operation failures and stack traces, each search attempt's start-time input/settings snapshot and elapsed time, returned inventory counters, progress/logs, and every displayed proposal's stock and casting-group allocation. Current-session attempts and older retained/opened proposals are distinguished. Missing counters from an interrupted/failed search are reported as unknown. A no-result bounded search is not described as proof of infeasibility. The report reads memory without rerunning the solver, rereading the DXF, changing the selection, or changing the project's dirty flag.

Source reconciliation: the uploaded **Top50-1.1.16-Source.zip** was compared with PR168's `bb37debee36f9d6a9dbce79bc41f3d47bdb35b6b` tree. Only its 33 additions/changes were applied in a separate feature checkout, then preserved in a source snapshot commit. Existing beam calculation/import files, unlimited raw selection reading, complete diagnostic IDs and the newer Revit selection callback remain intact. PR168 stays unmodified and unmerged.

The original Top50 candidate discovery, ranking, capacities and numerical algorithms are unchanged by this UI/diagnosis work. Original solver parity remains unresolved: the handover reported a fresh 95 m / 10-group solution versus the original 96.25 m / 11-group result. The original DXF, saved project and workbook were not included in this source ZIP. New checks use clearly identified controlled manual/DXF inputs, not reference results or hardcoded production answers. Prior 1.1.16 evidence is historical, not a new validation run.

The new Windows check compiles the actual shipping Revit2024/net48/x64 add-in, runs fresh native searches, validates allocations independently, exercises cancellation/failure/retry, project and workbook operations, raw/reviewed DXF reporting and missing-source diagnosis, and clicks the real diagnosis UI. It renders the dashboard and all five planner pages at several sizes/scales. Existing reader and numerical import regressions run separately. Installed-payload checks use temporary isolated installation folders, compare shipping files, verify absolute registrations, preserve existing settings and saved files, back up the previous beam assembly and reject live-host/custom-registration/downgrade cases.

For local testing, close all Revit windows and run the supplied **DokaEngineeringDashboard_Top50_Setup_1.1.17.0.exe** under your normal Windows account. The installer uses the existing Top50 per-user registration and upgrade-backup approach. Review its introductory information before installation. This build is a test release; actual Revit2024 host acceptance and native dependency coexistence still require testing on your computer. No company update feed is published and neither PR is merged by preparing this package.
